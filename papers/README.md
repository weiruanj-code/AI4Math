# Papers

Each subdirectory contains one independently identifiable manuscript. Use a
stable, lowercase, search-friendly slug and keep the paper's source, latest
PDF, and a detailed paper-specific README together.

## Current papers

- [`universal_quadratic_pgl2_orbit_shells/`](universal_quadratic_pgl2_orbit_shells/):
  represented quadratic $PGL_2$ orbit shells and rank-one orientation
  reciprocity.

## Directory convention

```text
papers/<paper-slug>/
├── README.md       # summary, scope, keywords, citation, build instructions
├── <paper>.tex     # source, when applicable
└── <paper>.pdf     # latest compiled artifact, when applicable
```
